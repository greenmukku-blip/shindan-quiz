# まおりゅう 手持ちティア評価

ユーザーの手持ちキャラを1体ずつ特定し、**キャラ自体の強さ**（育成度は無視）で現環境のティアに入れ、根拠を添えて返す。過去のセッションで評価済みのキャラは `references/roster.md` にあるので、まずそれを読んで重複を避ける。

## 進め方

### 1. 入力を読む

- **スクショ**：そのまま読む。
- **画面録画（mp4）**：フレームを抜き出してから読む。ffmpeg が無ければ `pip install --target <作業用dir> imageio-ffmpeg` で入る。
  ```bash
  FF=$(PYTHONPATH=<作業用dir> python3 -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
  "$FF" -i input.mp4 -vf "fps=2,scale=-2:1100" -q:v 3 frames/f_%02d.jpg
  ```
  キャラが切り替わったフレームだけ読めば足りる。同じ録画が2回送られることがあるので、md5 で重複を確認する。
- **ローカルのフォルダパス**（`C:\Users\...` など）：このセッションがユーザーのPC上で動いていれば直接読む。クラウドのセッションならPCには届かないので、画像を貼ってもらう。

### 2. 各キャラから読み取る項目

二つ名［ ］とキャラ名、★、Lv／上限、覚醒、EP、属性、物理/魔法、戦略タイプ（速攻・集撃・耐久・中立）、成長型、勢力、装備（Lv）または刻印符。

- **戦闘キャラと加護キャラを見分ける。** 加護キャラは画面に「刻印符」と施設ボーナス（◯の魔法装置+200%、加護の象徴+100%）があり、属性・勢力の欄がない。**加護は戦闘キャラと別のティア表**で評価する。
- 属性が「虚空・剛地・冥闇・閃光・烈火・疾風」などの**上位属性**なら、進化・★7化を経た新しい世代のことが多い。

### 3. 重複を除く

`references/roster.md` の評価済みキャラと二つ名で照合する。既出キャラは「育成状況だけ更新」と伝え、ティアは変えない。

### 4. 調べる

- WebSearch で `まおりゅう <略称><キャラ名>[<二つ名>]の評価とスキル` と検索する。攻略サイトは「水着ヒナタ[静心聖夏]」「炎霊シズ[炎霊武装]」のような略称で載っていることが多い。
- 環境によっては AppMedia・神ゲー攻略などの攻略サイトへの直接アクセスがブロックされる。その場合は検索結果の要約から拾い、**「検索要約からの情報」だと回答で明記する**。
- 総合ランキング（最新の Tier 表）と個別ページの両方を当たる。現環境のトップ層と出典は `references/tier-sources.md` にまとめてある。ここは日付が古くなるので、毎回最新の情報を検索で確かめる。

### 5. ティアを付ける

段階は **SSS > SS > S > A > B > C > D**。

- **最新のランキング記事・Tier 表に載っていれば、その順位を使う。** 根拠欄に「サイト：〜」と書く。
- 載っていなければスキル性能から判断し、「性能：〜」と書く。評価の軸は、まおりゅうが毎ターン6コンボを回すゲームなので **魔創魂変換 ＞ 高倍率バフ ＞ 耐性DOWN ＞ 単体火力** の順に重い。勢力や属性の縛りが強いもの、相方が必須のものは下げる。
- 1年以上前の記事で「最強」評価だったキャラは、★7化以降の新世代に押されているので A 止まりにする。
- 情報が取れなかったキャラは「暫定」と明記して B か C に置き、スキル画面のスクショを頼む。
- **育成度（Lv・凸・装備・EP）でティアを上下させない。** ユーザーが明確にそう求めた基準。

### 6. 回答の形

```
## 新規◯体
| キャラ | ティア | 根拠 |
（各キャラ：サイトの順位 or 性能の要点、弱み・条件があれば一言）

## 現時点の全体（戦闘◯体）
| ティア | キャラ |

（加護があれば加護のティア表も別に）

Sources: 使った URL を Markdown リンクで列挙
```

- 日本語で、簡潔に。既出キャラの説明を繰り返さない。
- 手持ちの中で噛み合う組み合わせ（攻略記事が名指ししている相方など）があれば一言添える。
- 評価したら、可能なら `references/roster.md` に追記して次回に引き継ぐ。

## 育成・編成の相談をされたとき

攻略動画の要約を貼られたり、「何から育てる？」と聞かれたら、`references/growth-guide.md` を読み、内容を**手持ちに当てはめて**答える。一般論の要約を返すのではなく、「このキャラの装備がLv10」「この特性キャラを持っていない」のように、手持ちの具体的な穴を指摘する。

## 注意

- このゲームの評価は周年・★7化で大きく動く。断定は出典がある範囲にとどめる。
- 表記揺れが多い：「境界ノ盟主」と「鏡界ノ盟主」、「狂美ノ化身」と「化神」、「精魔ノ黄士」と「黄土」、「協心」と「堅閃」など。似た名前は同じキャラとして扱い、そう書き添える。
