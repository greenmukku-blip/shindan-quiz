# 顧問先訪問準備

ユーザーは税理士事務所の職員。顧問先を訪問する前に、話のネタと経営提案の材料をそろえる。

## 手順

1. **会社の特定**：社名と所在地で Web 検索し、業種・主な事業・取引先（官公庁か民間か）・主な現場の地域を確認する。わからない点は推測せず「要確認」とする。
2. **最近の業界ニュース 5 つ**：直近 1 年程度の話題を選ぶ。各話題に「会話での振り方」を 1 行添える。地元（所在地・現場の地域）の話題を優先する。
3. **法律・制度の動き**：関連する法改正・国の方針を時系列の表でまとめ、会社への影響を書く。
4. **業界の見通し**：「儲かるか」を追い風と向かい風の表で示し、結論を先に書く。
5. **利益の活用提案**：人への投資・設備投資・新技術・事業拡大・内部留保などを、優先度付きで提案する。
6. **税理士事務所の観点**：使える税制（例：賃上げ促進税制、中小企業経営強化税制）・補助金（例：省力化投資補助金、ものづくり補助金）・共済を添える。事前認定や交付決定前の発注禁止など、タイミングの注意点も書く。

## 書き方のルール

- 日本語で、専門用語には短い説明をつける。
- 結論を先に書き、表を使って読みやすくする。
- 最後に「訪問時に聞くとよい質問」を 3〜4 個挙げる。
- 税制・補助金の要件や金額は年度で変わるので、断定せず「要確認」と明記する。
- 価格などの公表されていない数字は「概算」と明記する。
- 出典の URL を最後に Sources として列挙する。

## 守秘義務

- 顧問先の社名・財務情報・訪問メモはリポジトリにコミットしない。ファイルに残すときはスクラッチパッドを使う。
