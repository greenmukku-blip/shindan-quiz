# アカイイト 月間ファン数集計

データとスクリプトは `uma-fan-count/` にある（ブランチ `claude/uma-musume-fan-count-ns1l6d`）。
まず `uma-fan-count/README.md` と最新の `baseline_*.csv` を読むこと。

## 1. 動画からファン数を読み取る
メンバー一覧（総獲得ファン数・降順）を上から下までスクロールした縦長の録画（1320x2868）が来る。

```bash
V=<動画パス>; S=<scratchpad>
ffprobe -v error -show_entries format=duration "$V"
# リスト部分だけ切り出し、番号付きで6コマずつ並べる
ffmpeg -v error -i "$V" -vf "fps=8,crop=1200:980:60:1320,scale=600:-1,drawtext=text='%{n}':x=5:y=5:fontsize=24:fontcolor=red,tile=3x2" $S/p_%02d.png
```
- 画像は全部 Read して、名前・役職・総獲得ファン数を全員分拾う。上部の「メンバー 29/30」の人数と行数が合うか必ず確認する。
- 速くスクロールして飛んだ区間は `-ss <秒> -t 1` で fps を上げて取り直す。
- 名前「…」の人が実在するので注意（3点リーダーそのものが名前）。
- 読み取った値は `uma-fan-count/snapshot_YYYY-MM-DD_HHMM.csv`（列 `name,role,total_fans`）に保存する。

## 2. 新メンバーの扱い
月の途中で加入した人は基準値がない。加入直後の総獲得ファン数を、その月の `baseline_YYYY-MM-01.csv` の末尾に追記し、README に加入日と値を書く。
（例：10月は はおー 10/01、れんちょ 10/02 を追記済み）

## 3. 集計と投稿文
```bash
python3 uma-fan-count/tally.py uma-fan-count/baseline_YYYY-MM-01.csv uma-fan-count/snapshot_….csv <月>
```
獲得数一覧・2500万以下の人（除名候補）・投稿文が出る。基準値なし／月末不在の人は※で表示される。

投稿文の書式（サークルチャット1通に3人ずつ、コピペしやすいよう1通ずつコードブロックで渡す）：
```
☆10月ファン獲得数サークル内ランキング☆
上位15名まで発表します。いつもランキング維持に大きく貢献して下さり、本当にありがとうございます！
●1位：○○さん@4．5億●2位：○○さん@3億●3位：○○さん@9800万
…（15位まで）
☆以上TOP15名でした☆
```
- **サークルチャットは1通80文字まで**（81文字目以降は切れて送られる。2026/10/27に確認）。投稿文は1通ずつ必ず80文字以内に収める。全角・半角・記号も1文字として数える。超える場合は分割するか言い回しを短くする。
- 1億以上は小数1桁の「億」（小数点は全角「．」、整数なら「3億」）、1億未満は「万」。
- 全員に「さん」を付ける。

## 4. 月末の締め
- 月末の値を次月の基準値 `baseline_YYYY-(MM+1)-01.csv` として保存する（月初の録画が別にあればそちらを優先）。
- 獲得数が2500万以下の人、最終ログインが7日近い人を一覧にして伝える（除名はサブリーダーが判断）。
- 変更はコミットしてブランチに push する。

## サークルのルール・体制（2026/10 時点）
- 目標：月2500万。7日ログインなし、または月2500万以下で除名（事情がある人は掲示板かプロフ欄に記載）。
- リーダー：にゃんこ。サブリーダー：リヴァイバル、ふろん。集計担当はふろんさん（このスキルの利用者）。

## チャット録画の書き起こし
サークルチャットの録画が来たら、チャット部分（`crop=1320:900:0:1440` 付近）を同様にタイル化して読み、発言者・時刻ごとに書き起こす。スタンプは［　］で表記。体制やルールの変更があれば README に追記する。
