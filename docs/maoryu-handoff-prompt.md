## 1. ティア評価の基準（私が決めたルール）

- **育成度（Lv・凸・覚醒・装備・EP）は無視して、キャラ自体の強さで評価する。** EPが高いから上、Lv1だから下、という判断はしない。
- 段階は **SSS > SS > S > A > B > C > D**。戦闘キャラと加護キャラは**別々のティア表**にする。
- 判断の順番：
  1. **最新のランキング記事・Tier表**に載っていれば、その位置を使う。根拠欄に「サイト：〜」と書く。
  2. 載っていなければ**スキル性能**から判断する。根拠欄に「性能：〜」と書く。
  3. 情報が取れなければ「暫定」と明記してB〜Cに置き、ゲーム内のスキル画面のスクショを頼む。
- まおりゅうは毎ターン6コンボを組むゲームなので、性能の評価軸は **魔創魂変換 ＞ 高倍率バフ ＞ 耐性DOWN ＞ 単体火力** の順に重い。勢力・属性の縛りが強いもの、特定の相方が必須のものは下げる。
- 1年以上前の記事で「最強」だったキャラは、★7化以降の新世代に押されているので**A止まり**にする。
- 1体ごとに「強い理由」と「弱み・条件」を添える。

## 2. 作業の進め方

### 2-1. 入力の読み方
- **スクショ**：そのまま読む。
- **画面録画（mp4）**：フレームを抜き出して読む。ffmpegが無ければ `pip install --target <作業用dir> imageio-ffmpeg` で入れ、`fps=2` くらいで抜き出す。キャラが切り替わるフレームだけ読めば足りる。**同じ録画が2回送られることがある**ので、md5で重複を確認する。
- **ローカルフォルダのパス**（例：`C:\Users\green\Desktop\まおりゅう`）：このセッションが私のPC上で動いていれば直接読む。クラウドのセッションならPCには届かないので、そう伝えて画像を貼ってもらう。

### 2-2. 各キャラから読み取る項目
二つ名［ ］とキャラ名、★、Lv／上限、覚醒、EP、属性、物理/魔法、戦略タイプ（速攻・集撃・耐久・中立）、成長型、勢力、装備Lv（または刻印符）。

- **戦闘キャラと加護キャラの見分け方**：加護キャラの画面には「刻印符」と施設ボーナス（「◯の魔法装置 +200%」「加護の象徴 +100%」）があり、属性・勢力の欄がない。
- 属性が **虚空・剛地・冥闇・閃光・烈火・疾風** などの上位属性なら、進化・★7化を経た新しい世代であることが多い。
- 才能解放・覚醒のアイコンに赤い「！」が付いていたら、進められる状態の目印だと思われる（確定ではない）。

### 2-3. 重複チェック
下の「4. 評価済みの手持ち」と二つ名で照合する。既出なら「育成状況だけ更新」と伝え、ティアは変えない。

### 2-4. 調べ方
- WebSearch で `まおりゅう <略称><キャラ名>[<二つ名>]の評価とスキル` と検索する。攻略サイトでは「水着ヒナタ[静心聖夏]」「炎霊シズ[炎霊武装]」「クリスマスシュナ[偶像鬼巫女]」のような略称で載っている。
- **AppMedia・神ゲー攻略・GameWithなどの攻略サイトは、環境によっては直接開けない（403でブロックされる）。** その場合は検索結果の要約から拾い、回答に「検索要約からの情報」と明記する。
- 総合ランキング（最新のTier表）と、キャラの個別ページの両方を当たる。
- 回答の最後に、使ったURLを「Sources:」としてMarkdownリンクで並べる。

### 2-5. 表記揺れ（同じキャラとして扱う）
「境界ノ盟主」と「鏡界ノ盟主」、「狂美ノ化身」と「化神」、「精魔ノ黄士」と「黄土」、「全能ノ化身」と「化神」、「協心」と「堅閃」、「閻魔竜女」と「闇魔竜女」。
