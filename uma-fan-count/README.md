# ウマ娘 サークル「アカイイト」月間ファン数集計

## データ
- `baseline_2026-10-01.csv` … 2026/10/01 07:23 録画時点の各メンバーの総獲得ファン数（累計）28名＋加入後に追加したはおーさん＝29名。
  10月の獲得数 = 10月末の総獲得ファン数 − この値。
- 2026/10/01 のチャットで体制が決定：にゃんこさんはリーダー継続（脱退は撤回）、
  集計はふろんさん、集計通知のフォローとメンバー募集はリヴァイバルさん、除名はサブリーダーが実行。
- はおーさんが 10/01 朝（基準値の録画後）に加入。加入後のスクショ（10/01）の総獲得ファン数 3,015,464,989 を
  基準値としてCSVの末尾に追加済み（他の人より少し後の時点の値）。
- サークルのルール：月末に獲得ファン数Top15を掲示。7日ログインなし、または1ヶ月の獲得ファン数が2500万以下なら除名
  （事情がある場合は掲示板かプロフィール欄に書いてもらう）。

## 手順（毎月末）
1. サークル情報 → メンバー一覧を「総獲得ファン数・降順」でスクロールした動画を受け取る
2. 全員の総獲得ファン数を読み取り、前回基準との差分＝当月獲得数を計算
3. 下記フォーマットで上位15名のコメント文を作る
4. 読み取った値を次月の基準 `baseline_YYYY-MM-01.csv` として保存

